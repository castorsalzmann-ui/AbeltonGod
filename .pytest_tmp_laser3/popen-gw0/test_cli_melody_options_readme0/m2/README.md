* Chosen by option, not derived from a preset: the bass roll positions (`roll`), the snare/clap/rim hit positions (`*_pattern`), kick positions (four on the floor), all velocities, the energy thresholds at which a voice enters. These are defaults, not measured facts about Goa.

The MIDI bass notes are key-dependent (they start at MIDI 26 for this key and follow the scale), so the sampler pitch of the bass one-shot must be matched to the key by hand.

Defaults are only defaults (D-027); no value above is a measured fact about Goa.

## Import

1. New Live set. Drag the `.mid` onto the Arrangement at bar 1: one MIDI track per element below is expected (not verified).
2. If Live does not take the tempo, set 145 BPM by hand.
3. Put an instrument on every track (the file has no devices). Melodic tracks: Drift (in every Live 12 edition), Analog is the second recipe. Rhythm tracks: the one-shot WAVs in `samples/` (rendered by the kick, bass, hat, snare, clap and rim engines from the presets above; a voice that is off has no WAV) in a Drum Rack or Simpler.
