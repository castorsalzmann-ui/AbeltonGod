## Option reference

- `--density 0-1` (global or `lead=0.5,arp=1`): notes per bar lead round(d*8), arp/pluck round(d*16); pad: chord length 4-round(3d) bars (never silent).
- `--register -2..2` octaves (global or per voice).
- `--length 1-16` bars per phrase; `--scale`, `--root`, `--bpm 135-150`.
- `--sections Name:bars:energy:voice+voice,...`: energy 0-1 scales density by 0.5+0.5*energy and velocity by 0.70+0.30*energy.
